# PoC artifacts (sanitized)

This folder contains sanitized proof-of-concept artifacts for the Juice Shop internship task.
- `review_request_sanitized.txt` — sanitized HTTP request showing the stored review submission (tokens/cookies redacted).
- `stored-xss_product1_review.png` — screenshot of the stored review on product page.

**Important:** Raw PoCs or full request logs that contain tokens, cookies or secrets are *not* included here deliberately. If reviewers need access to raw artifacts, provide them only via a private branch or secure transfer.
